## PROJECT.md
Project: GSD Todo — Mobile-First Personal Organizer
Goal: A Todoist-style mobile app in Godot 4.6 with Tasks, Notes, and expandable Stats/Visuals.
Stack: Godot 4.6, GDScript, Godot Resources (.tres)
Target: Android/iOS mobile (primary), desktop (secondary)

## FEATURES
1. **Task Manager**: Grouped list (Expired / Todo / Completed), create/edit/complete/delete, deadline date picker.
2. **Notes**: Separate tab, list of notes (title + body), tap to open and edit freely.
3. **App Shell**: Tab bar (Tasks, Notes, Stats-placeholder), 3-dot menu (Send JSON stub, Stats stub, Quit).
4. **Local Persistence**: Native Godot Resources (.tres) for speed and simplicity.
5. **Expandable**: Stats/Visuals, reschedule changelog, note collections — later milestones.

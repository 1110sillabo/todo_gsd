<task type="auto">
  <name>Task 1: Enable text wrapping on TitleLabel in task_row.tscn and note_row.tscn</name>
  <files>src/ui/task_row.tscn, src/ui/note_row.tscn</files>
  <action>
In task_row.tscn, find the TitleLabel node (path: MarginContainer/VBoxContainer/TitleLabel) and add:
```
autowrap_mode = 3
```
(Value 3 = TextServer.AUTOWRAP_WORD_SMART — wraps at word boundaries, falls back to character boundary)

Also ensure the TitleLabel does NOT have `clip_text = true` (which would override wrapping). Remove that property if present.

Apply the same change to note_row.tscn on its TitleLabel node (path: MarginContainer/TitleLabel).

Do NOT add `custom_minimum_size` to the labels — let them grow with content. The parent VBoxContainer/PanelContainer will expand naturally.
  </action>
  <verify>
In Godot editor, instantiate task_row.tscn in a test scene with a long title string ("This is a very long task title that should wrap onto two lines"). Confirm the row grows vertically and the text wraps instead of clipping.
  </verify>
  <done>TitleLabel in both task_row.tscn and note_row.tscn has autowrap_mode=3. Long titles wrap instead of overflowing.</done>
</task>

<task type="auto">
  <name>Task 2: Fix note editor vertical scroll and increase section header touch target</name>
  <files>src/ui/note_edit_dialog.tscn, src/ui/group_section.tscn</files>
  <action>
**note_edit_dialog.tscn — ContentEdit scroll:**
Find the ContentEdit node (TextEdit, path: VBoxContainer/ContentEdit).
Set:
```
custom_minimum_size = Vector2(0, 320)
size_flags_vertical = 3
```
(size_flags_vertical = 3 = SIZE_FILL + SIZE_EXPAND, so it stretches inside the VBoxContainer and gains enough height to scroll)

The AcceptDialog popup itself: if it has a fixed size, ensure it is large enough. Set `min_size = Vector2(360, 500)` on the AcceptDialog root node so there is room for both TitleEdit and the ContentEdit.

TextEdit nodes scroll vertically by default in Godot 4 — the fix is purely giving ContentEdit enough space.

**group_section.tscn — HeaderPanel touch target:**
Find the HeaderPanel node (PanelContainer).
Set:
```
custom_minimum_size = Vector2(0, 56)
```
This ensures the header is at least 56px tall, making it easy to tap on mobile (48dp minimum touch target + margin).
  </action>
  <verify>
1. Open a note in the editor, paste 20 lines of text into ContentEdit. Confirm you can scroll vertically within the TextEdit.
2. In Godot editor, inspect group_section.tscn and confirm HeaderPanel custom_minimum_size.y >= 56.
  </verify>
  <done>ContentEdit scrolls vertically for long notes. HeaderPanel is ≥56px tall. Section headers tap reliably.</done>
</task>

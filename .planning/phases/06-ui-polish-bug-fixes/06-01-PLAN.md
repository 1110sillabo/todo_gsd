<task type="auto">
  <name>Task 1: Fix vertical scroll in task_list_view.tscn and notes_list_view.tscn</name>
  <files>src/ui/task_list_view.tscn, src/ui/notes_list_view.tscn</files>
  <action>
In both .tscn files, find the ScrollContainer node and set:
- `scroll_deadzone = 30` — gives input system tolerance before committing to scroll axis
- The FABButton node in task_list_view.tscn and notes_list_view.tscn must have `mouse_filter = 2` (MOUSE_FILTER_IGNORE). This prevents the FAB from consuming touch events that begin over its area, which was blocking vertical scroll gestures initiated from the lower part of the screen. In .tscn syntax: `mouse_filter = 2` under the FABButton node properties.

Note: Do NOT change any anchor/offset values on existing nodes — only add the two properties above.
  </action>
  <verify>Open both .tscn files and confirm `scroll_deadzone = 30` is present on ScrollContainer and `mouse_filter = 2` on FABButton.</verify>
  <done>Both files have scroll_deadzone and FAB has MOUSE_FILTER_IGNORE. Scrolling does not get stuck when gesture starts near FAB area.</done>
</task>

<task type="auto">
  <name>Task 2: Increase tab bar height in main_scene.tscn</name>
  <files>src/ui/main_scene.tscn</files>
  <action>
In main_scene.tscn, find the TabContainer node. Add a theme override for tab bar minimum height. In Godot 4, this is done by setting a `theme_override_constants/tab_separation` or adding a minimum height via the `tab_bar` sub-node if accessible.

The most reliable approach: Find or add a `TabBar` child node under TabContainer and set `custom_minimum_size = Vector2(0, 56)` on it.

Alternatively, add to the TabContainer node:
```
theme_override_constants/tab_separation = 8
theme_override_constants/icon_max_width = 0
```

And add a TabBar node override:
```
[node name="TabContainer" type="TabContainer"]
theme_override_constants/tab_separation = 8
```

Target tab height: at minimum 52px (current is likely ~32px). Check the current tab bar height in project.godot or main_scene.tscn and increase by 20px minimum.

If the TabContainer tab bar cannot be sized directly, set `custom_minimum_size.y = 56` on the TabContainer itself and adjust `offset_top` on the inner content nodes (TaskListView, NotesListView) accordingly so they still fill the remaining area.
  </action>
  <verify>Open main_scene.tscn and confirm tab bar node has increased minimum size. Run in Godot editor and visually confirm tabs are taller.</verify>
  <done>Tab bar height is at least 52px tall. Tabs are easy to tap on a 400×860 viewport.</done>
</task>

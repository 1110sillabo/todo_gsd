  <name>Task 1: Sort "Da fare" tasks by deadline ascending in task_list_view.gd</name>
  <files>src/ui/task_list_view.gd</files>
  <action>
In `_load_tasks()` (or wherever tasks are categorized and added to group sections), after building the `todo_tasks` array and before adding its items to the group section, sort by `deadline` ascending — tasks with closest deadline first. Tasks with `deadline == 0` (no deadline set) should go to the END of the list (lowest priority).

Add this sort after building todo_tasks array:
```gdscript
# Sort Da fare by closest deadline first. Tasks with no deadline go last.
todo_tasks.sort_custom(func(a: TaskResource, b: TaskResource) -> bool:
    if a.deadline == 0 and b.deadline == 0:
        return false
    if a.deadline == 0:
        return false  # a has no deadline → goes after b
    if b.deadline == 0:
        return true   # b has no deadline → a goes before b
    return a.deadline < b.deadline  # both have deadlines: sort ascending
)
```

Read the actual function name and variable names from the file first — adapt accordingly. Do not hardcode array names.

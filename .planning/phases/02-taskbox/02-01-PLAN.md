<task type="auto">
  <name>Task 1: Add task_id field to TaskResource and fix filename to use UUID</name>
  <files>src/resources/task_resource.gd, src/persistence/persistence_manager.gd</files>
  <action>
    Add `@export var task_id: String = ""` to TaskResource. In `_init()`, if `task_id` is
    empty, generate one: `task_id = "%d_%d" % [Time.get_ticks_msec(), randi()]`.
    This gives a unique stable ID per task.

    In PersistenceManager.save_task(), change the filename from:
      `task.title.validate_filename() + ".tres"`
    to:
      `task.task_id + ".tres"`

    Keep all other methods unchanged. load_task, list_tasks, delete_task all still work
    with filenames — no change needed there since callers always get filenames from list_tasks().
  </action>
  <verify>
    grep -n "task_id" src/resources/task_resource.gd  # must show export + _init assignment
    grep -n "task_id" src/persistence/persistence_manager.gd  # must show task_id in save path
  </verify>
  <done>Two tasks with the same title produce two separate .tres files.</done>
</task>

<task type="auto">
  <name>Task 2: Register PersistenceManager as autoload in project.godot</name>
  <files>project.godot</files>
  <action>
    Add the autoload entry to project.godot under the [autoload] section (create section if
    absent). The entry must be:
      `PersistenceManager="*res://src/persistence/persistence_manager.gd"`

    The `*` prefix tells Godot to instantiate it as a singleton node in the scene tree.
    After this change, any script can call `PersistenceManager.save_task(task)` without
    `var pm := PersistenceManager.new()`.

    Also change `extends Node` at the top of persistence_manager.gd to just leave it as-is
    (Node is correct for autoloads). Verify _init() still initializes the directory.
  </action>
  <verify>
    grep -n "PersistenceManager" project.godot  # must show autoload entry
    grep -n "autoload" project.godot             # must show [autoload] section
  </verify>
  <done>Godot editor and headless runner can access PersistenceManager as a global singleton.</done>
</task>

# Phase 05-01: App Shell & Export — PLAN

## Overview

Add a ⋮ (three-dot) `MenuButton` to the top-left of the MainScene header.
Its `PopupMenu` has three items: **Send JSON** (exports all data to a JSON file),
**Stats** (disabled stub), and **Quit** (same as existing ✕ button).
`_export_json()` reads all data from `PersistenceManager`, serializes it, writes
`todo_export.json` to Downloads (Android) or user_data dir (desktop), then shows
an Italian-language `AcceptDialog` confirming the save path.

## Pre-conditions

- Phase 04 complete; `main_scene.tscn` / `main_scene.gd` compile and run.
- `PersistenceManager` autoload is registered in `project.godot`.
- `export_presets.cfg` exists at project root with an `[preset.0.options]` section.

#### Node to add

Add a **`MenuButton`** node as a **direct child of the root `Control`** node,
placed **before** `ExitButton` in the scene tree (so ExitButton retains highest
input priority as the last child).

**Node name:** `MenuButton`

**Inspector properties to set:**

| Property | Value |
|---|---|
| `text` | `⋮` |
| `layout_mode` | `0` (anchors) |
| `anchor_left` | `0.0` |
| `anchor_top` | `0.0` |
| `anchor_right` | `0.0` |
| `anchor_bottom` | `0.0` |
| `offset_left` | `4` |
| `offset_top` | `4` |
| `offset_right` | `52` |
| `offset_bottom` | `52` |
| `custom_minimum_size` | `Vector2(48, 48)` |
| `flat` | `true` |
| `focus_mode` | `0` (None — avoids keyboard focus stealing on mobile) |

Setting `custom_minimum_size = Vector2(48, 48)` ensures Godot's stretch system
scales the touch target correctly relative to the viewport (400×860 canvas_items
stretch). 48 px in canvas units ≈ 48 dp on the target device density. This
mirrors the approach that should also be applied to ✕ ExitButton if it isn't
already set.

Task 3 (`_ready()`), so no additional editor configuration is needed here.

#### 3d — Implement _export_json()

```gdscript
func _export_json() -> void:
	# --- Collect tasks ---
	var tasks_arr: Array = []
	for filename in PersistenceManager.list_tasks():
		var t: TaskResource = PersistenceManager.load_task(filename)
		if t == null:
			push_warning("_export_json: skipping corrupt task file: " + filename)
			continue
		tasks_arr.append({
			"id":               t.task_id,
			"title":            t.title,
			"description":      t.description,
			"created_at":       _unix_to_iso(t.created_at),
			"deadline":         _unix_to_iso(t.deadline),
			"completed_at":     _unix_to_iso(t.completed_at),
			"reschedule_count": t.reschedule_count,
			"tags":             t.tags,
		})

	# --- Collect notes ---
	var notes_arr: Array = []
	for filename in PersistenceManager.list_notes():
		var n: NoteResource = PersistenceManager.load_note(filename)
		if n == null:
			push_warning("_export_json: skipping corrupt note file: " + filename)
			continue
		notes_arr.append({
			"title":      n.title,
			"content":    n.content,
			"created_at": _unix_to_iso(n.created_at),
		})

	# --- Collect lists ---
	var lists_arr: Array = []
	for filename in PersistenceManager.list_lists():
		var l: ListResource = PersistenceManager.load_list(filename)
		if l == null:
			push_warning("_export_json: skipping corrupt list file: " + filename)
			continue
		var items_arr: Array = []
		for item in l.items:
			items_arr.append({
				"text":    item.title,   # ListItemResource.title maps to JSON "text"
				"checked": item.checked,
			})
		lists_arr.append({
			"id":         l.list_id,
			"title":      l.title,
			"created_at": _unix_to_iso(l.created_at),
			"items":      items_arr,
		})

	# --- Build root dict ---
	var payload: Dictionary = {
		"exported_at": Time.get_datetime_string_from_unix_time(
				Time.get_unix_time_from_system(), true),
		"tasks":  tasks_arr,
		"notes":  notes_arr,
		"lists":  lists_arr,
	}

	# --- Determine output path ---
	var path: String
	var label: String
	if OS.has_feature("android"):
		path  = OS.get_system_dir(OS.SYSTEM_DIR_DOWNLOADS) + "/todo_export.json"
		label = "Download/todo_export.json"
	else:
		path  = OS.get_user_data_dir() + "/todo_export.json"
		label = path

	# --- Write file ---
	var file: FileAccess = FileAccess.open(path, FileAccess.WRITE)
	if file == null:
		_show_dialog("Errore: impossibile scrivere il file.\n" + path)
		return
	file.store_string(JSON.stringify(payload, "\t"))
	file.close()

	# --- Confirm ---
	_show_dialog("Salvato in " + label)


func _unix_to_iso(unix: int) -> Variant:
	if unix == 0:
		return null
	return Time.get_datetime_string_from_unix_time(unix, true)


func _show_dialog(msg: String) -> void:
	var d := AcceptDialog.new()
	d.dialog_text = msg
	add_child(d)
	d.popup_centered()
	# Auto-free after user dismisses
	d.confirmed.connect(d.queue_free)
	d.canceled.connect(d.queue_free)
```

## Threat Model

### Trust Boundaries

| Boundary | Description |
|---|---|
| GDScript → Filesystem | Path construction for export file (user_data dir is sandboxed; Downloads dir is world-readable on Android) |
| GDScript → PersistenceManager | Data read from local file storage — no network, no external input |

### STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|---|---|---|---|---|
| T-05-01 | Information Disclosure | `todo_export.json` in Downloads | accept | Downloads folder is user-controlled; data is the user's own. No PII beyond what user entered. |
| T-05-02 | Tampering | Path construction in `_export_json` | mitigate | Path built entirely from `OS.get_system_dir` / `OS.get_user_data_dir` — no user-supplied segments. No path traversal possible. |
| T-05-03 | Denial of Service | `FileAccess.open` returns null | mitigate | Null-check implemented; show error dialog, do not crash. |
| T-05-04 | Information Disclosure | JSON contains all user data | accept | Export is an explicit user action (two taps required). No auto-export, no network transmission. |

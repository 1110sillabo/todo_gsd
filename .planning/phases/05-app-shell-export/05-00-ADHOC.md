### Android export — build pipeline
- **How the build was activated**: Godot 4 Android export requires:
  1. Android SDK (user has `~/Library/Android/sdk/` on Mac)
  2. Java JDK (Temurin 17 at `/Library/Java/JavaVirtualMachines/temurin-17.jdk/`)
  3. A debug/release keystore (Godot generates one automatically on first export)
  4. Godot Editor → Export → Android preset → set SDK path + JDK path in Editor Settings
  5. Build: Project → Export → Export Project (not "Export PCK")
- Godot writes the APK directly (no Gradle build needed for debug exports without custom modules).
- Output file: `GSDTodo_1.apk` (path set in export preset `export_path`).

### Android export — architecture fix
- **Problem**: First APK failed with `INSTALL_FAILED_NO_MATCHING_ABIS` on Galaxy A13.
- **Root cause**: Galaxy A13 (SM-A135F) runs Android 14 but is a 32-bit ARM device (`armeabi-v7a`), not `arm64-v8a`.
- **Fix**: In export preset → Architectures, checked **both** `armeabi-v7a` AND `arm64-v8a`.
- APK now installs successfully on device.

## Open Blockers

### Android orientation — landscape instead of portrait ⚠️

**Symptom**: App launches in landscape on Galaxy A13 despite portrait setting in `project.godot`.

**Root cause identified**: The Android Manifest orientation is written from `export_presets.cfg`, **not** from `project.godot`. The key `screen/orientation` was missing from `export_presets.cfg`; only `permissions/set_orientation=true` was present (which enables the permission but does not set the value). Godot then defaults to landscape (0).

**Fix applied (2026-05-09)**: Added `screen/orientation=1` to `export_presets.cfg` under the `screen/` block. Values: 0=landscape, 1=portrait, 2=reverse-landscape, 3=reverse-portrait.

**Status**: Fix committed, APK not yet re-exported. Next step: re-export APK → install → verify portrait on device.

**Verification command** (on Mac, after re-export):
```bash
~/Library/Android/sdk/build-tools/$(ls ~/Library/Android/sdk/build-tools/ | tail -1)/aapt dump badging GSDTodo_1.apk | grep orientation
```
Should show: `android:screenOrientation='portrait'`
